# Brand source masters

Full-resolution mascot and logo artwork. Not served by the app.

The web build uses optimized derivatives in `apps/web/public/brand/`, produced
by `pnpm brand:build` (see `scripts/build-brand.mjs`). Re-run that script after
replacing any master here.

| File | Use |
| --- | --- |
| `mascot-fire.png` | Hero. Mascot breathing fire at tokens. |
| `mascot-torch.png` | Full body holding a flaming coin. Empty states. |
| `mascot-head.png` | Head with embers. Compact accents. |
| `mascot-winking.jpg` / `mascot-sitting.jpg` / `mascot-running.jpg` | Studio renders on white. |
| `emblem.png` | Circular badge. App icon and nav mark. |
| `wordmark.png` | RH INCINERATOR lockup. |
| `banner.png` | Mascot + wordmark. Social card source. |
| `free-burns.png` | FREE BURNS badge. |
| `mascot-fire.mp4` / `mascot-skating.mp4` / `mascot-chasing.mp4` | Motion clips, unused for now. |
